# Design: PostgreSQL Foundation

## Technical Approach

Embed-at-source pattern (mirrors `references/embed.go` from Issue #2): `migrations/embed.go` co-locates with `001_esquema_inicial.sql`, exposing `var EsquemaInicial string`. The `postgres` infrastructure package imports `migrations` for the raw DDL and executes it via pgxpool. Docker Compose + Make targets provide the local lifecycle. Single SQL source; idempotent DDL; no migration tracking table.

## Architecture Decisions

| Decision | Alternatives Considered | Rationale |
|----------|------------------------|-----------|
| Embed package at `migrations/` | Copy SQL to `internal/`, read at runtime, embed from `cmd/` | Only legal single-source option; `//go:embed` forbids `..`; mirrors Issue #2 pattern |
| `pgxpool.New` + `pool.Ping` in `Conectar` | Manual `pgx.Connect` + custom pool | pgxpool is idiomatic pgx v5; auto-reconnect, health-aware; Issue #4 expects `*pgxpool.Pool` |
| `pool.Exec(ctx, sql)` without transaction | `BEGIN;...COMMIT;` wrapping | DDL with `IF NOT EXISTS` is inherently idempotent; Postgres auto-commits DDL; avoids deadlock risk |
| `string` embed type (not `[]byte` / `embed.FS`) | `embed.FS` for multi-file | Phase 0 has exactly one migration; `string` is simpler and `pool.Exec` accepts string directly |
| Docker Compose healthcheck (`pg_isready`) | TCP wait, sleep loop | Native Postgres readiness; compose `depends_on: condition: service_healthy` guarantees ready state |

## Data Flow

```
migrations/001_esquema_inicial.sql
       │ [go:embed]
       ▼
migrations.EsquemaInicial (string)
       │ [import]
       ▼
postgres.Migrar(ctx, pool) ─── pool.Exec(ctx, sql) ───→ PostgreSQL
       ▲
       │ pool returned by
postgres.Conectar(ctx, url) ── pgxpool.New ── pool.Ping ──→ PostgreSQL
```

Composition root (Issue #4) calls: `Conectar` → `Migrar` → application ready.

## Interfaces / Contracts

```go
// migrations/embed.go
package migrations

import _ "embed"

//go:embed 001_esquema_inicial.sql
var EsquemaInicial string
```

```go
// internal/infrastructure/postgres/conectar.go
package postgres

import (
    "context"
    "fmt"
    "github.com/jackc/pgx/v5/pgxpool"
)

func Conectar(ctx context.Context, databaseURL string) (*pgxpool.Pool, error) {
    pool, err := pgxpool.New(ctx, databaseURL)
    if err != nil {
        return nil, fmt.Errorf("postgres.Conectar: pool: %w", err)
    }
    if err := pool.Ping(ctx); err != nil {
        pool.Close()
        return nil, fmt.Errorf("postgres.Conectar: ping: %w", err)
    }
    return pool, nil
}
```

```go
// internal/infrastructure/postgres/migrar.go
package postgres

import (
    "context"
    "fmt"
    "github.com/jackc/pgx/v5/pgxpool"
    "github.com/Unikyri/vivi-perfilamiento-leads/migrations"
)

func Migrar(ctx context.Context, pool *pgxpool.Pool) error {
    _, err := pool.Exec(ctx, migrations.EsquemaInicial)
    if err != nil {
        return fmt.Errorf("postgres.Migrar: %w", err)
    }
    return nil
}
```

## Testing Strategy

| Layer | What to Test | Approach |
|-------|-------------|----------|
| Build | `go build ./...` compiles with pgx imported | CI command |
| Build | `go vet ./...` clean | CI command |
| Integration | `make db-up` → container healthy in ≤10s | Docker healthcheck + `docker compose ps` |
| Integration | `make db-validate` → 7 tables exist after migration | `psql` table count query |
| Integration | Idempotency: run migration twice, no error | `psql < sql` twice; second exits 0 |
| Integration | `make db-reset` → clean slate, re-validates | Sequence: reset → validate |
| Smoke | `Conectar` returns pool on valid URL | Requires running container |
| Smoke | `Conectar` returns error on invalid URL | Unit-testable without Docker |

**Executable validation commands:**
```bash
# Build gate (no Docker required)
go build ./...
go vet ./...

# Docker lifecycle (requires Docker)
make db-up
make db-validate          # applies SQL, asserts 7 tables
make db-validate          # idempotency: second run exits 0
make db-reset
make db-down

# Table count verification (inside db-validate)
psql "$DATABASE_URL" -t -c \
  "SELECT count(*) FROM information_schema.tables WHERE table_schema='public';" \
  | tr -d ' ' | grep -q '^7$'
```

## Migration / Rollout

No production data exists. Rollback: `git revert` + `docker compose down -v`. The migration is idempotent by design — safe to re-run on any environment.
