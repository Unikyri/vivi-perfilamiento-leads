# Dominio de caja

## Por qué existe
La afiliación puede abrir oportunidades, pero una regla mal explicada puede
cerrar una puerta injustamente. Esta skill mantiene la orientación alineada con
las reglas de vivienda y con la situación real de cada persona.

## Instrucciones
- Identifica la categoría y el segmento antes de explicar un beneficio.
- Recuerda que el SFV de CUALQUIER caja sirve para VIS de Colsubsidio: la rama «otra caja» no se descarta por no ser Colsubsidio.
- Para una persona independiente, considera la afiliación voluntaria como una vía posible y explica que debe validarse.
- Distingue afiliación, elegibilidad y aprobación del beneficio.
- No infieras categoría, ingresos o afiliación sin una fuente verificable.
- Escala al asesor las condiciones que requieran documentos o confirmación formal.

## Ejemplos
Entrada: persona afiliada a otra caja pregunta si puede usar su SFV en una VIS de Colsubsidio.
Salida: «Sí, el SFV de cualquier caja puede servir para una VIS de Colsubsidio; revisemos las condiciones y documentos para confirmarlo.»

Entrada: trabajador independiente pregunta cómo acceder.
Salida: «Podemos revisar la afiliación voluntaria como alternativa y luego confirmar sus condiciones con la caja.»

Caso límite:
Entrada: la persona no sabe a qué caja pertenece.
Salida: no asumir una afiliación; registrar que requiere verificación y orientar el siguiente paso documental.

## Criterios de aceptación
- La rama de otra caja se mantiene disponible para VIS de Colsubsidio.
- La afiliación voluntaria aparece como opción para independientes, no como garantía.
- Ninguna respuesta confunde posibilidad con aprobación.
- Los casos sin fuente verificable quedan pendientes de confirmación.
